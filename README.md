# React Demo

This is a small React app created to learn the basics of React development.

## What it does

The app displays a simple landing page with:

- a header introducing the project
- student information cards
- a counter that can be increased or decreased
- a button that shows a welcome alert when clicked

It is a beginner-friendly example that demonstrates core React concepts such as components, props, state, and event handling.

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the local URL shown in the terminal in your browser.

## Tech stack

- React
- Vite
- JavaScript
